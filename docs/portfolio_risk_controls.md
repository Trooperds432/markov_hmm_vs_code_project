# Portfolio Risk Controls

Portfolio mode adds rebalance and concentration controls: max weight, cash buffer, minimum
rebalance change, max turnover, correlation penalty, optional sector caps, score thresholds, and
score decay settings.

New reports:
`portfolio_risk_report.csv`, `portfolio_rebalance_decisions.csv`,
`portfolio_correlation_matrix.csv`, and `portfolio_constraint_report.csv`.

Use the rebalance decision report to see why each symbol was bought, sold, held, or scaled.
