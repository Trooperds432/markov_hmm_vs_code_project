# Random Baselines

Random baselines ask whether the HMM added timing value beyond random exposure to the same returns.

The framework writes matched variants for exposure, turnover, rebalance dates, long-only behavior,
and portfolio-style paths. `random_baseline_summary.csv` reports HMM return, Sharpe, drawdown,
random percentiles, and the fraction of random paths beating the HMM.

These are robustness diagnostics, not profitability claims.
