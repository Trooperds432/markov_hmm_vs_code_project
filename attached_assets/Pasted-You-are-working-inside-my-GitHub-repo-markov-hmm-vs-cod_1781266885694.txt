You are working inside my GitHub repo: markov_hmm_vs_code_project.

Goal:
Convert my existing Python HMM / neural-network quant research repo into a ready-made web application with an institutional, Bloomberg-like quant terminal experience. The app should be accessible through Replit and should provide a professional UI for running backtests, viewing model diagnostics, comparing strategies, inspecting HMM regimes, inspecting NN confirmation signals, checking stress tests, viewing portfolio outputs, and running paper-trading simulations.

Important product framing:
This is not a live trading system, not financial advice, and not a guaranteed-profit bot. The repo should be presented as an institutional quant research terminal / AI regime research terminal for research and educational use. Paper trading must remain simulation-only. Do not add live broker execution.

Core app direction:
Build a full React + FastAPI web app that becomes the main user interface for the repo, while preserving the existing CLI underneath. The CLI should still work, but the app should provide a polished UI that lets the user run backtests, stream progress/status, and inspect outputs visually.
